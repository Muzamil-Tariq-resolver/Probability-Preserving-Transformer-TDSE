# Probability-Preserving Transformer for the TDSE

This repository presents a Probability-Preserving Transformer (PPT) for learning the temporal evolution of the one-dimensional Time-Dependent Schrödinger Equation (TDSE).

The main idea is to combine the sequence-learning capability of a Transformer with a fundamental physical constraint: probability conservation.

For a quantum wavefunction, the total probability must remain normalized:

$$
P(t)=\int |\psi(x,t)|^2dx=1.
$$

A standard neural network may produce a numerically accurate wavefunction while violating this physical requirement. Instead of enforcing probability conservation through an additional penalty term in the loss function, the proposed PPT applies hard normalization directly to the predicted wavefunction:

$$
\psi_{\mathrm{pred}}
\rightarrow
\frac{\psi_{\mathrm{pred}}}
{\sqrt{
\Delta x\sum_i|\psi_{\mathrm{pred},i}|^2
}}.
$$

This ensures that every predicted quantum state satisfies discrete probability conservation.

The model is trained using reference solutions generated by the Crank–Nicolson method for a particle confined in a one-dimensional infinite potential well. A multi-token temporal input window of consecutive wavefunction states is provided to the Transformer, which predicts the next quantum state.
